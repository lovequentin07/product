## 서비스 개요
- **서비스명**: 농수축산물 시세
- **URL**: `datazip.net/market`
- **타겟**: 장 볼 때 지금 가격이 적당한지 확인하고 싶은 주부

## 데이터 출처
| API | 제공 데이터 | 명세 |
|-----|-----------|------|
| KAMIS | 도·소매가격, 가격추이, 지역별 가격 | `.claude/api/wholesale_retail_api/kamis/kamis-api.md` |
| 가락시장 (공공데이터포털) | 등급별 가격, 수입농산물 가격, 반입물량, 5개년 가격 | `.claude/api/wholesale_retail_api/dataportal/dataportal-api.md` |
| 농림축산식품부 | 품목 표준코드, 수입실적, 출하량 | `.claude/api/wholesale_retail_api/mafra/mafra-api.md` |

## 개발 순서
1. mock 데이터로 프론트엔드 완성
2. API 연결
